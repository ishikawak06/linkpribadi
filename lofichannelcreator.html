Panduan Platform
★
Suno AI — Cara Pakai 1. Buka suno.com → klik "Create"
2. Pilih mode "Custom" (bukan Simple)
3. Paste bagian STYLE TAGS ke kolom "Style of Music"
4. Paste bagian LYRICS/INSTRUMENTAL ke kolom "Lyrics" — atau ketik "[Instrumental]" jika tidak mau ada vokal
5. Isi kolom "Title" dengan nama track
6. Klik Create — Suno generate 2 versi sekaligus
7. Download versi yang paling cocok
✓ Gratis
10 lagu/hari di tier gratis
⚠ Catatan
Cek terms soal royalty-free untuk monetisasi
★
Udio — Cara Pakai 1. Buka udio.com → Login/daftar gratis
2. Di kolom prompt, paste bagian PROMPT UTAMA
3. Klik icon pengaturan → aktifkan "Instrumental"
4. Set durasi ke Full Song atau pilih durasi manual
5. Klik Create
6. Setelah generate, kamu bisa extend track agar lebih panjang
7. Download via tombol di pojok kanan lagu
✓ Gratis
~10 lagu/hari tier gratis
⚠ Catatan
Hasil kadang lebih pendek, extend berkali-kali
★
Stable Audio — Cara Pakai 1. Buka stableaudio.com → Daftar akun
2. Paste PROMPT UTAMA ke kolom teks
3. Set Duration sesuai kebutuhan (max 3 menit di tier gratis)
4. Klik Generate
5. Stable Audio fokus pada instrumental — tidak perlu setting tambahan
6. Download audio MP3/WAV langsung
★ Kelebihan
Kualitas audio sangat baik, format WAV
✗ Batasan
Max 3 menit di gratis, perlu extend manual
★
Mubert — Cara Pakai 1. Buka mubert.com → Login gratis
2. Pilih tab "Generate"
3. Paste MOOD TAGS ke kolom pencarian/prompt
4. Atur Duration hingga 25 menit
5. Klik Generate Track
6. Mubert sangat cocok untuk lofi panjang dan livestream
7. Download untuk penggunaan personal gratis
✓ Kelebihan
Bisa generate hingga 25 menit sekaligus
⚠ Catatan
Perlu upgrade untuk monetisasi komersial
